## Published · The current foundation

**v0.0.5-alpha.1** provides typed functions, contracts, numerical vectors and tiles, runtime budgets, and relative source modules. This is the [published baseline](/development/), with experimental syntax and APIs.

## Next priorities · Make modules easier to work with

The compiler repository lists module tooling, additional conformance, and source navigation as its next priorities. These are development directions; they do not imply a completed feature or a release date.

## Planned · Stronger language and library foundations

The source roadmap then calls for:

1. Explicit constant-expression and library organization design.
2. User-defined types and callable values.
3. A compiler backend and developer tooling.
4. Domain-specific libraries.

See the [reviewed compiler roadmap](https://github.com/scarp-lang/scarp/blob/afe8b5380c9d6c4774162e51c6c9bc8b90901671/README.md#prototype-limits-and-planned-roadmap) for the upstream ordering. Priorities may change as implementation reveals new requirements.

## Future vision · AI development with less friction

Scarp aims to make AI development more approachable through language and tooling design. Today's numerical values are an early foundation. A complete AI framework, automatic differentiation, GPU execution, general tensors, and a mature package ecosystem require separate design and implementation milestones.

[Explore the AI direction →](/ai/)

## Toward v1.0.0

A stable release should be grounded in a documented language contract, reliable tools and packages, conformance tests, compatibility expectations, and clear limitations. These are readiness goals for this project hub, not a claim that the compiler team has committed to a fixed release checklist.

There is no announced v1.0.0 date. We track concrete capabilities and reviewed evidence instead of arbitrary completion percentages.
